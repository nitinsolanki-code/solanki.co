Recommended Additional Fields

Fields worth adding to make the vCard more complete

Field What It Does iOS Android Priority
ADR;TYPE=WORK Business address — shows on map, enables navigation from contact card ✓ Maps link ✓ Maps link High
NOTE Brief bio or context line — visible when viewing the contact. Good for "Founder of Solanki Co — Family holding company" ✓ Shows in Notes ✓ Shows in Notes High
BDAY Birthday — triggers annual reminders on both platforms ✓ Calendar alert ✓ Calendar alert Medium
X-ABDATE (Anniversary) Custom date field — can label as "Anniversary" or any custom date ✓ Custom label ✗ Ignored Low
X-ABRELATEDNAMES Related people — "assistant", "spouse", "partner" ✓ "Related People" ✓ "Relations" Low
GEO Latitude/longitude — enables location-based features ✗ Not shown ✗ Not shown Low

Key takeaway: iOS supports richer contact features (social profiles, custom labels, phonetic names). Android ignores most Apple-specific extensions but handles the core fields well. The three unlabeled URLs should ideally get X-ABLabel tags so iOS can show descriptive labels like "Website", "Digital Card", and "Personal Site" instead of generic "homepage" entries.
