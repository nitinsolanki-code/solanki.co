## Signature Setup (Outlook)

### What You Have

Two files in your website folder:

- **solanki-email-signature.html** — The signature HTML to paste into Outlook
- **solanki-email-template.html** — Visual reference for how emails should look and read (open in browser)

### Outlook for Mac / Windows (New Outlook)

1. Open Outlook → Settings (gear icon) → Accounts → Signatures
2. Click **+ New Signature**, name it "Solanki Co"
3. Open `solanki-email-signature.html` in a browser (Chrome, Safari, Edge)
4. Select everything on the page (Cmd+A / Ctrl+A), then Copy (Cmd+C / Ctrl+C)
5. Back in Outlook, click inside the signature editor and Paste (Cmd+V / Ctrl+V)
6. Set as default for new messages and replies
7. Send a test email to yourself to verify formatting

### Outlook on the Web (outlook.com / Microsoft 365)

1. Go to outlook.com → Settings (gear) → Mail → Compose and reply
2. Under "Email signature," click **+ New signature**
3. Name it "Solanki Co"
4. Open `solanki-email-signature.html` in a browser, select all, copy
5. Paste into the signature editor
6. Set as default, save

### Classic Outlook for Windows

1. Open the signature file in a browser, select all, copy
2. In Outlook → File → Options → Mail → Signatures
3. Click "New," name it "Solanki Co"
4. Paste into the editor
5. Set as default for new messages and replies

### Troubleshooting

- **Circle not rendering?** Some Outlook versions don't support `border-radius`. The S will still appear in its taupe background — it just displays as a square. This is acceptable; most recipients on Gmail/Apple Mail will see the circle correctly.
- **Fonts look different?** The signature uses Georgia (serif, for the name) and Helvetica/Arial (sans-serif, for details). These are system-safe fonts that match the brand's Cormorant Garamond and Inter as closely as possible without requiring web font loading.
- **Spacing off?** After pasting, check that the thin vertical divider line appears between the S mark and the name block. If it's missing, try pasting into a plain HTML editor first.

## Email Font Settings (Outlook)

Configure your default compose font to match the brand:

### Font

- **Compose font:** Helvetica Neue or Arial
- **Size:** 11pt
- **Weight:** Regular (not bold)
- **Color:** #313131 (the brand's soft black — in Outlook's custom color picker, enter `31` for R, `31` for G, `31` for B)

### How to Set in Outlook

1. Settings → Mail → Compose and reply
2. Under "Message format," click the font dropdown
3. Set to Arial or Helvetica, 11pt, color #313131
4. Apply to both new messages and replies/forwards

## Writing Style

### Voice

Warm, direct, and confident. You're speaking to someone you respect — not pitching them. The Solanki Co tone is quiet authority, never aggressive, never casual-sloppy.

### Structure

Every email should be short enough that the recipient can read it in under 30 seconds:

- **Opening:** One line. Direct and warm. Skip "Hope this finds you well."
- **Body:** 2-3 sentences. Clear, specific, value-forward.
- **Close:** One clear ask. "Would Thursday or Friday work?" not "Let me know your thoughts whenever."
- **Sign-off:** "Best," or "Warmly," then your first name only.

### Subject Lines

- Lowercase, conversational
- No brackets, no emojis, no ALL CAPS
- Examples: "quick question," "following up on [topic]," "a thought on [their company]"

### What to Avoid

- "Hope this finds you well" / "Hope you're doing great!"
- "Just circling back" / "Per my last email"
- Multiple exclamation marks (one max per email, and sparingly)
- Emojis anywhere in the email
- Bold or colored text in the body
- Long paragraphs — break at 2-3 sentences
- Bullet points in outreach emails (save for internal/operational)
- "Thanks!" as a sign-off

### Sign-offs by Context

| Context | Sign-off |
|---------|----------|
| First outreach | Best, Nitin |
| Warm / relationship | Warmly, Nitin |
| Follow-up | Best, Nitin |
| Formal / institutional | Regards, Nitin Solanki |

## Per-Pillar Email Guidelines

When emailing on behalf of a specific pillar, adjust the context line but keep the same signature:

| Pillar | Subject Example | Opening Context |
|--------|----------------|-----------------|
| Capital (Mora Sol Capital) | "re: [deal name]" | "Reaching out from Mora Sol Capital regarding..." |
| Advisory (Mora Sol Advisory) | "[their company] — a thought" | "I advise a handful of founders at similar inflection points..." |
| Digital (Mora Sol Digital) | "automation for [their process]" | "We build productized systems at Mora Sol Digital..." |
| Studios (Mora Sol Studios) | "content partnership" | "Through Mora Sol Studios, we produce..." |
| Foundation | "the solanki foundation" | "I'm reaching out on behalf of The Solanki Foundation..." |
| Travel (Solanki Private Travel) | "a trip idea" | "Through Solanki Private Travel..." |

For Foundation and Travel emails specifically, you may eventually want dedicated signatures. For now, the master Solanki Co signature works across all pillars.
